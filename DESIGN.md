# Design System

## Direction

MarginHatch uses a premium fintech visual language for UK marketplace sellers: an almost-white canvas, slate text, saturated blue emphasis, white surfaces, and fine neutral rules. The interface prioritizes comparing estimates and editing sale inputs over decorative dashboard elements.

## Tokens

| Role | Value |
| --- | --- |
| Main background | `#FFFDFA` |
| Main text | `#212833` |
| Muted text | `#71717a` |
| Accent blue | `#0061FE` |
| Light border | `#E5E7EB` |
| Card background | `#FFFFFF` |
| Accent tint | `#F7FAFF` |

Body and control text use `"Helvetica Neue", Arial, sans-serif`; section headings use `ui-serif, Georgia, Cambria, "Times New Roman", Times, serif`.

## Layout

The calculator places sale inputs beside ranked platform estimates on desktop, with supporting saved calculations and source notes below. Input groups use equal columns with a 24px gap and collapse to one column at 768px. The input panel stays sticky on wide screens; mobile uses a single-column flow and a fixed comparison shortcut.

## Components

Input labels sit above spacious white controls with 8px corners, fine borders, and blue focus rings. Fieldset legends are 20px serif section headings. Results use restrained surfaces and separators; expandable profit details show revenue, total costs, and total profit as aligned rows, with profit emphasized in blue.

## Accessibility

Keyboard focus uses a visible blue border and three-pixel ring. Text and interactive states retain readable contrast, reduced-motion preferences are respected, and the mobile shortcut's accessible name follows its visible action.
